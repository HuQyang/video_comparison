# 生成视频多维标注台

参考 GeoT2V 标注模板，采用左侧对比组列表、中间视频与 prompt、右侧问题和细节标签的布局。每组 A/B/C 独立标注，可以全部适用或全部不适用。展示编号一致；界面不显示模型名称。

## 运行与发布

在本目录运行 `python3 -m http.server 8081`，打开 http://localhost:8081 。将本目录内容放在 GitHub 仓库根目录，Settings → Pages 选择 main 分支 / (root) 发布。也可以使用附带的 Actions 工作流。新增 `schema.js` 必须一起提交。

## 问题与细节

每段视频填写七道核心问题：镜头是否真的移动、场景变化、静态三维场景适用性、清晰度、运镜与 prompt 符合度、刚性、异常严重程度。所有问题都有“说不准”。场景变化允许合理动态和不合理变化同时存在。

细节标签可多选，包括镜头异常、人物/动物/风/水烟火等合理动态、非刚性形变、物体漂移、几何畸变、出现消失、结构变化、闪烁、清晰度与画面问题。另有异常时间段和备注。

视频元数据加载后自动记录像素宽高、时长；不推断清晰度、编码质量或帧率。清晰度需要人工填写。标签含义和稳定代码定义在 `schema.js`，JSON 导出带完整标签字典。

## 保存与导出

所有选择和备注立即保存在浏览器，刷新续评。七题有效时视频计入完成；“保存并下一段”会检查必填项。A/B/C、上一段和下一段允许切换未完成视频，草稿保留。

JSON/CSV 可随时导出；未完成项为 null/空值，不会当成负面评价。CSV 每段视频一行，每个细节代码单独一列。JSON 同时记录组 id、视频 id、随机顺序、method、prompt、七题标签、细节、备注、元数据与作答时间。作答时间为各次编辑间累计的页面停留时间，不是严格的观看时长。

新版保存键与旧三选一记录隔离，旧结果不会转换成新标签，也不会删除。可以点“导出旧版三选一结果”下载当前浏览器的旧记录。旧记录只在仍使用相同 study id/version 的情况下找到。

结果不会自动上传，标注者必须下载或复制给研究者。不要将结果提交到公开仓库。配置仍在 `study-config.js`，内容变化时递增 version；不要修改自动生成配置中的视频映射。
